# 玩家手册

本手册面向在网页版中游玩的玩家，包含通用规则、每种记分卡变体的完整规则与界面操作说明。
规则出处与更多版本的调研见 [rules-research.md](rules-research.md)。

## 快速上手

```bash
pnpm install
pnpm dev     # 打开终端提示的地址（默认 http://localhost:5173）
```

设置页中：

1. **玩家**：1–5 名，每名可选「人类」或六档 AI：随机 / 贪心 / 启发式 /
   **神经网络（最强·推荐，默认对手）** / 前瞻 / 深度前瞻（较慢，
   每步会现场模拟多局）。神经网络 AI 目前只针对经典棋盘训练，
   在其他记分卡上自动退回启发式水平；
2. **座位顺序**：座位 1 先手，Connected 变体还按座位分配 A–E 卡面。
   「随机座位」立刻打乱当前名单；勾选「每局开始时随机」后，每次开始都会按
   **本局种子**确定性地重新就座——同一个种子仍然重现同一局，包括座位；
3. **记分卡**：12 个官方预设 + 1 个随机变体（见下文各变体规则）。
   选中带特殊机制的记分卡时，右侧对局预览会先列出它的连锁规则；
4. **随机种子**：相同的种子 + 相同的选择 = 完全相同的一局，方便复盘与和 AI 比较。

对局中：

- 骰子区显示 2 白 + 4 彩骰；被移除的骰子显示为灰色 ✕；
- 轮到人类玩家时，**可划的格子会加深色描边**，点击即划记；「跳过」按钮放弃本阶段；
- 绿色光晕 = 当前决策者；黄色边框 + 「主动」徽章 = 本回合的主动玩家；
- 每张卡片实时显示当前得分与失误数，下方对局记录列出每一步；
- 玩这些带连锁机制的记分卡时，卡片顶部会多出一条**变体面板**，把引擎里
  「看不见」的那部分状态摊开：奖励轨轮到第几格、下一次触发拿什么颜色、
  哪几组交换还没作废、哪两格互为一对。把鼠标放到面板里任意一项（触摸屏点一下），
  记分卡上对应的格子会被点亮；再点一次取消。连锁真正发生时，对局记录也会
  单独记一条（🔗 自动划记 / 🎁 奖励轨触发 / ✨ 集齐符号）。

## 通用规则（所有变体一致）

1. **回合流程**：主动玩家掷全部骰子，之后严格按顺序执行两步：
   - **动作 1（白骰和）**：两枚白骰之和，**所有玩家**都可以（不强制）划在自己任意一行中数值相符的一格；
   - **动作 2（白 + 彩）**：**只有主动玩家**可以再选一枚白骰 + 一枚在场彩骰，把和划在对应颜色的格子上。
2. **从左往右**：每行新划的格子必须在已划格子右侧；跳过的格子永远不能回头补划。
3. **锁定**：想划一行的行尾锁定格，必须先在该行划满门槛数量（经典 5 格）；划下锁定格后该行对**所有人**封闭，对应彩骰移出游戏，锁定格本身额外 +1 计数。同一个动作 1 窗口内，其他满足条件的玩家可以同时划该格一起锁行。
4. **失误**：主动玩家两步合计一格未划 → 强制记 1 次失误（终局 -5 分）；非主动玩家跳过无代价。
5. **游戏结束**：累计锁定 2 行，或任何人记满 4 次失误 → **立即**结束（若第 2 行在动作 1 中锁定，动作 2 不再执行、不记失误）。
6. **计分**：每个计分组按划记数查表——划 n 格得 n(n+1)/2 分（1, 3, 6, 10, 15, 21, 28, 36, 45, 55, 66, 78, …），总分 = 各组之和 − 失误 ×5。最高分获胜，并列共同获胜。

## 各变体规则

### 经典 Qwixx（`classic`）

- 红、黄行：2→12 升序；绿、蓝行：12→2 降序，各 11 格；
- 锁定格：红 12 / 黄 12 / 绿 2 / 蓝 2，门槛 5 格；
- 单行满贯 11 格 + 锁定 = 12 计数 = 78 分。

### gemixxt 变体 A（`gemixxt-a`，混色·数字有序）

- 数字顺序与经典版相同，但每行内**颜色混排**（同一数字在四行中四色各出现一次）；
- 动作 2 的「白 + 彩」只能划**对应颜色**的格子——它可能在任何一行；
- 锁行时移除的是**该行最右格颜色**的骰子；该颜色骰移除后，其他行中该颜色的格子仍可用白骰和划；
- 计分仍按**行**。

### gemixxt 变体 B（`gemixxt-b`，单色·数字乱序）

- 四行仍整行单色，但行内**数字乱序**——合法性只看位置（从左往右），与数字大小无关；
- 锁定数字各行不同：红 11 / 黄 10 / 绿 3 / 蓝 4（官方卡面）；
- 其余与经典版一致。

> 两个 gemixxt 卡面的具体格子排列为本项目自拟（满足官方结构约束），官方未公开电子版卡面数据。

### Qwixx Longo（`longo`）

- 使用**八面骰**（点数 1–8），白骰和范围 2–16；
- 四行加长为 2→16 / 16→2，各 15 格；
- **锁定**：行尾**最后两个数字任一**（红/黄 15、16；绿/蓝 3、2）可锁行，门槛提高为已划 **6** 格；
- **幸运数字**：每名玩家开局分到 2 个（显示在卡片顶部 ⭐ 徽章）。动作 1 中白骰和等于你的幸运数字时，可以**改为**在你当前划记最少的未锁定行中划下**下一个可划的格子**（不跳格；并列最少任选其一）。整局可反复触发，也可以用它锁行（须满足全部锁行条件）。界面上幸运划记的目标格会带 ⭐ 标记；
- 计分表延伸：13x=91、14x=105、15x=120。

### Qwixx Big Points（`big-points`）

- 四行与经典版相同；红/黄行之间与绿/蓝行之间各有一条**圆形双色奖励行**（数字与相邻列相同）；
- **划奖励格的条件**（两者都要满足）：
  1. 相邻两个普通格（正上/正下）至少一个已被你划过；
  2. 再次掷出同样的数——动作 1 白骰和等于该数（**任何玩家**都可用），或动作 2 彩骰组合凑出该数且**颜色与你已划的相邻格相同**（仅主动玩家）；
- 奖励行同样**从左往右**、跳过不补；
- 奖励格不计入锁行门槛；相邻行被锁后奖励格**仍可继续划**；主动玩家本回合只划了奖励格也**不算失误**；
- **计分**：奖励格计入**相邻两行**的划记数，每行最多计 **15** 个（120 分封顶）。

### Qwixx Double A / B（`double-a` / `double-b`）

- 两版锁行门槛都提高到 **7 个叉**，每行最多按 16 个叉计 136 分；
- A：每行最近划下的数字可在以后再次掷出时划第二个叉；第二叉不推进该行位置；
- B：每行 3、5、9、11（降序行对应 10、8、6、4）是双倍格，一次划下直接计两个叉。

### Qwixx Bonus A（`bonus-a`）

- 四行共有 12 个 ◆ 奖励格；命中后从左到右消耗奖励颜色轨，并必须在指定颜色行划下下一个可划格；
- 追加格若又是 ◆ 会继续连锁；某颜色锁定后，奖励轨上尚未使用的同色格全部作废。

### Qwixx Bonus B（`bonus-b`）

- 集齐同种两个符号即触发：○ 在当前最少行追加 2 格；◇ 四行各追加 1 格；
  □ 最少行终局翻倍；⬡ 终局 +13；✹ 失误仍会结束游戏但不再扣分；
- 即时奖励必须执行，界面会进入“奖励追加”阶段并只点亮合法的下一格。

### Qwixx Connected A / B（`connected-steps` / `connected-chain`）

- 每个座位自动分到 A–E 中不同的数字卡面；
- 阶梯：11 个「阶」格既计入原颜色行，也组成第五计分组（最高 66 分）；
- 连锁：划下「链」格会自动划下配对的另一端，无视从左到右与行锁定限制。

### Qwixx X-Change（`x-change`）

- 白骰阶段可使用卡下方 9 组交换之一，把两白骰和值换成配对数字后再划；
- 交换格同样从左到右：可以跳过，但跳过和用过的格以后都不能再用；只影响使用者本人。

### 随机混排（`random`）

- 非官方娱乐变体：每局按种子随机生成卡面——每行数字为 2..12 的随机排列、颜色混排（每色恰 11 格）；
- 规则同 gemixxt（锁行移除行尾格颜色的骰子，按行计分）。

## 常见问题

| 问题 | 答案 |
|---|---|
| 两枚白骰可以分开当两个数用吗？ | 不可以，只能求和。 |
| 主动玩家可以跳过白骰和、只用白+彩吗？ | 可以，两步各自可选；只要合计划了 ≥1 格就不吃失误。 |
| 一回合能在同一行划两格吗？ | 可以（动作 1 + 动作 2 各一格），第二格必须更靠右（可紧邻）。 |
| 别人锁行的同一轮我还能划最后一格吗？ | 同一个动作 1 窗口内可以，前提是你自己也满足门槛；之后（含该回合动作 2）不行。 |
| 失误可以主动吃吗？ | 主动玩家可以两步都跳过来「自愿」吃失误（有时避免坏划记更划算）。 |
| 平局怎么算？ | 官方未规定；本实现为并列共同获胜。 |
